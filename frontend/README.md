# Расписание сушилок и стиралок
Данный сайт поможет студентам распределять расписание этих машин между собой.

Пользовательские сценарии (User Flow):

  Просмотр статуса: Пользователь заходит на главную страницу и сразу видит сетку машин (свободны, заняты, ожидают выгрузки).   
  
  Авторизация / Профиль: Нажатие на кнопку «Профиль» / «Войти» открывает модальное окно для входа в систему, после чего отображается имя пользователя и его активные бронирования. 
  
  Бронирование: Клик по конкретной машине открывает модальное окно с расписанием (календарём), где можно выбрать свободное время и занять машину.
