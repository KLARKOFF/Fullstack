# Frontend — Dryers & Washers

React 19 + TypeScript (strict), Vite, React Router. Без UI-библиотек и библиотек состояния: формы, загрузка данных, уведомления и модальные окна написаны своими силами в слое `shared`.

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # проверка типов + сборка
npm run lint     # oxlint
```

## Структура (Feature-Sliced Design, упрощённо)

```
src/
├── app/                      # сборка приложения
│   ├── App.tsx
│   ├── providers/            # все контексты в одном месте (AppProviders)
│   ├── router/               # маршруты и защита страниц (RequireAuth, RequireAdmin)
│   ├── layout/               # шапка + анимация смены страниц
│   └── styles/index.css
├── pages/                    # страницы — собирают виджеты, фичи и сущности
│   ├── home/                 # «/» — сетка машин
│   ├── profile/              # «/profile» — личный кабинет
│   └── admin/                # «/admin» — админ-панель
├── widgets/
│   └── header/               # шапка: название прачечной, вход, ссылки
├── features/                 # действия пользователя
│   ├── auth/                 # окно входа/регистрации, выход
│   ├── book-machine/         # выбор даты и слота, создание брони
│   ├── cancel-booking/       # отмена брони с подтверждением
│   ├── edit-profile/         # форма личных данных
│   ├── rename-laundry/       # смена названия прачечной
│   └── manage-machines/      # добавление, редактирование, удаление машин
├── entities/                 # сущности предметной области
│   ├── machine/              # тип, вычисление статуса, правила, API, контекст, карточка
│   ├── booking/              # тип, слоты расписания, API, контекст, строка брони
│   ├── user/                 # тип, правила, API, сессия, блок данных пользователя
│   └── laundry/              # тип, правила, API, контекст
└── shared/                   # не знает ничего о прачечной
    ├── api/                  # localStorage, ApiError, задержка мок-API
    ├── config/               # параметры расписания (совпадают с backend)
    ├── lib/                  # время, валидаторы, useForm, useResource, useNow
    └── ui/                   # Button, InputField, SelectField, Modal, Skeleton,
                              # ErrorState, EmptyState, уведомления, окно подтверждения
```

Внутри слайса код разложен по сегментам: `model/` (типы, правила, состояние), `api/` (запросы), `lib/` (вспомогательные функции), `ui/` (компоненты). Наружу слайс отдаёт только то, что перечислено в его `index.ts`.

### Правила импорта

1. Слой импортирует только нижележащие: `app → pages → widgets → features → entities → shared`.
2. Слайсы одного слоя не импортируют друг друга (например, `features/auth` не знает о `features/book-machine`). Если действие затрагивает две сущности, его собирает фича: удаление машины вместе с её бронями — `features/manage-machines/model/useDeleteMachine.ts`.
3. Импорт из другого слайса — только через его `index.ts` и алиас `@/`: `import { useMachines } from '@/entities/machine'`.

### Состояние

Данные хранятся в контекстах сущностей (`MachinesProvider`, `BookingsProvider`, `LaundryProvider`, `SessionProvider`), которые подключены в `app/providers/AppProviders.tsx`. Компоненты получают данные хуками (`useMachines()`, `useBookings()`, `useSession()`), поэтому страницам не нужно передавать данные через props. У каждого списка есть статус `loading | error | success` (хук `shared/lib/useResource.ts`) — по нему показываются скелетоны, ошибка с кнопкой «Повторить» или пустое состояние.

### Валидация

Правила записаны один раз в `entities/*/model/validation.ts` и совпадают со схемами backend. Их используют и формы (через `shared/lib/useForm.ts`), и мок-API. Ошибка поля появляется после ухода с поля или после попытки отправить форму; ошибка «сервера» показывается над кнопкой.

### Анимации

Только CSS (`app/styles/index.css`): появление и закрытие модальных окон, появление карточек «лесенкой», плавная смена цвета статуса машины и полосы прогресса, уведомления, мерцание скелетонов, подсветка строки при редактировании, переход между страницами. При системной настройке «уменьшить движение» анимации отключаются.
