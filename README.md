# Dryers & Washers — расписание стиралок и сушилок в общежитии

Веб-приложение помогает жильцам общежития делить между собой стиральные и сушильные машины: смотреть, какие машины свободны, бронировать время и управлять своими бронями. Администратор ведёт список машин прачечной.

## Стек

- **Frontend:** React 19 + TypeScript, Vite, React Router
- **Backend:** Python, FastAPI
- **База данных:** PostgreSQL, SQLAlchemy 2
- **Контроль версий:** Git

## Пользовательские сценарии

1. **Просмотр состояния машин.** На главной странице пользователь видит сетку машин и статус каждой: свободна, работает, ожидает выгрузки, на обслуживании. Статус вычисляется по расписанию броней; для работающей машины показаны оставшееся время и прогресс, для свободной — ближайшая бронь.
2. **Вход и регистрация.** Кнопка «Войти» открывает модальное окно. После входа в шапке отображается имя пользователя.
3. **Бронирование.** Клик по любой исправной машине открывает её расписание: пользователь выбирает дату (до 7 дней вперёд) и свободный часовой слот. Занятые слоты недоступны. Неавторизованному пользователю предлагается войти.
4. **Личный кабинет.** Пользователь видит и редактирует свои данные (имя, комната), просматривает и отменяет брони, выходит из аккаунта.
5. **Администрирование.** Администратор меняет название прачечной, добавляет, редактирует и удаляет машины.

## Требования

- Node.js 22 LTS или новее
- Python 3.11 или новее
- PostgreSQL
- Git

## Запуск frontend

```bash
cd frontend
npm install
npm run dev
```

Приложение откроется на http://localhost:5173.

Другие команды: `npm run build` — сборка, `npm run preview` — просмотр сборки, `npm run lint` — проверка линтером.

## Запуск backend

### Подготовка базы данных

Потом я сделаю docker, ну а пока придётся страдать с этим.

```bash
sudo -u postgres psql
```

```sql
CREATE USER laundry WITH PASSWORD 'ваш_пароль';
CREATE DATABASE laundry OWNER laundry;
```

### Настройка окружения

```bash
cd backend
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env
```

В скопированном .env поменяйте {PASSWORD} на свой пароль, а также сгенерируйте секрет.

### Запуск

Из каталога `backend`:

```bash
uvicorn app.main:app --reload
```

Проверка: http://localhost:8000/api/health должен вернуть `{"status": "ok"}`. Документация API: http://localhost:8000/docs.
